# วิธีเอาเกมขึ้นเว็บ (ให้ลงมือถือได้)

เกมเป็นไฟล์ static ทั้งหมดอยู่ในโฟลเดอร์ `public` ไม่ต้อง build อะไรเพิ่ม
ต้องเป็นที่อยู่แบบ **https** ถึงจะติดตั้งลงหน้าจอโฮมและเล่นออฟไลน์ได้

## ทางที่แนะนำ: Netlify (ฟรี)

1. เปิด https://app.netlify.com/drop
2. ลากโฟลเดอร์ `public` (ในโฟลเดอร์โปรเจกต์นี้) ไปวางในหน้าเว็บ
3. รอสักครู่ จะได้ที่อยู่แบบ `https://ชื่อสุ่ม.netlify.app`
4. กด **Claim your site / Log in** แล้วสมัครหรือเข้าสู่ระบบด้วยบัญชีของคุณ (ไม่งั้นเว็บจะหายใน 1 ชั่วโมง)
5. ตั้งชื่อเว็บได้ที่ Site configuration > Change site name เช่น `3000-miles-pinke`

## ทางเลือก: Cloudflare Pages

Workers & Pages > Create > Pages > Upload assets > อัปโหลดโฟลเดอร์ `public`

GitHub Pages: ใช้ได้เมื่อบัญชี GitHub มองเห็นได้ตามปกติ และ repo ต้องเป็น public

## ลงมือถือ

- Android (Chrome): เปิดที่อยู่เว็บ > เมนู ⋮ > **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอโฮม**
- iPhone (Safari): เปิดที่อยู่เว็บ > ปุ่มแชร์ > **เพิ่มไปยังหน้าจอโฮม**
- เปิดเกมจากไอคอนนั้น เล่นหนึ่งครั้งตอนมีเน็ตให้โหลดครบ หลังจากนั้นเล่นออฟไลน์ได้
- ข้อมูลความก้าวหน้าเก็บในเครื่อง สำรองเป็นไฟล์ที่ ตั้งค่า > สำรองข้อมูลเป็นไฟล์ เป็นระยะ

## อัปเดตเกมหลังมีขั้นใหม่

1. อัปโหลดโฟลเดอร์ `public` ซ้ำ (Netlify: Deploys > ลากโฟลเดอร์ `public` ไปวางในกล่อง "Drag and drop")
2. เปิดเกมบนมือถือตอนมีเน็ต จะมีข้อความ "มีเวอร์ชันใหม่" ให้กด **อัปเดต**
3. ขั้นที่เพิ่มแค่คำศัพท์ (ขั้น C) ไม่เปลี่ยนเวอร์ชัน แต่ต้องอัปโหลดซ้ำเหมือนกัน คำใหม่จะโหลดเองเมื่อเปิดเกมตอนมีเน็ต
